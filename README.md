# 分頁錄影機（Edge／Chrome 擴充功能）

> A Manifest V3 extension for Microsoft Edge and Google Chrome that records browser tabs: crop to a region, record several tabs at once, see the elapsed time on the toolbar badge, auto-split into segments, and recover recordings after a browser crash. The UI is in Traditional Chinese.

錄製瀏覽器分頁的擴充功能，完全在本機執行，不會上傳任何資料。支援：

- 同時錄好幾個分頁，每個分頁各自存檔
- 在網頁上拖框只錄一部分，範圍可以存成多組，下次一鍵套用
- 不會出現「正在分享這個分頁」那一列
- 工具列圖示上直接顯示錄影時間
- 每秒寫進硬碟，瀏覽器當掉也救得回來
- 每隔一段時間（預設 30 分鐘）自動存成一個檔案，接著錄下一段，不用重選分頁

## 安裝

1. 在 Edge 網址列輸入 `edge://extensions` 並打開。
2. 打開左側的「開發人員模式」。
3. 按「載入解壓縮」，選這個 `tab-recorder` 資料夾。
4. 建議把擴充功能固定到工具列：按工具列的拼圖圖示，在「分頁錄影機」旁邊按「在工具列中顯示」。這樣才看得到錄影時間。

修改程式後，在 `edge://extensions` 按這個擴充功能的「重新載入」。

## 使用方式

### 錄整個分頁

- 到要錄的分頁，按工具列圖示，再按「開始錄影」。
- 或直接按快捷鍵 `Alt+Shift+R`，再按一次就停止。快捷鍵可以到 `edge://extensions/shortcuts` 修改。

### 只錄一部分

1. 按工具列圖示，再按「在網頁上框選…」。
2. 在網頁上拖出範圍。拖框的內部可以移動，拖四個角可以調整大小。
3. 想留著下次用的話，輸入名稱後按「儲存範圍」。
4. 按「開始錄影」或 Enter 開始錄。按 Esc 取消。

下次要用同一組範圍，在彈出視窗的「範圍」選單選那一組，按「開始錄影」就好。如果現在的分頁大小跟存檔時不一樣，會跳出提醒，因為框的位置可能會偏掉。

### 自動框住影片

在「範圍」選單選「自動框住影片」再按「開始錄影」，會自動找出網頁裡最大、正在顯示的影片，只錄影片畫面本身（會扣掉影片上下或左右的黑邊）。

- 錄影中影片位置或大小改變（例如視窗縮放、版面變動），範圍會自動跟著移動，錄出來的檔案尺寸維持不變。
- 會讀取影片來源的規格，彈出視窗會顯示例如 `來源 720×1280 · 約 1.8 Mbps → 錄影 682×1214 · 6 Mbps`，方便判斷畫質是不是開太高。
- 錄影尺寸不會超過來源解析度：影片在畫面上被放大時，放大的部分沒有多出細節，只會讓檔案變大，所以只錄來源的解析度。
- 影片在畫面上比來源小時（例如來源 720×1280，畫面上只有 682×1214），會要求瀏覽器用更高的倍率重畫分頁（最多 2 倍），讓錄影盡量達到來源解析度。有沒有生效看彈出視窗：顯示「高解析擷取 1.08×」代表有；顯示「瀏覽器沒有提高解析度」代表這個瀏覽器不支援，會照畫面大小錄。
- 適合解析度常變動的情況，例如用遠端桌面連回家錄，不用重新框選。
- 網頁換頁後就不再追蹤，會停在最後的位置繼續錄。
- 選這個選項時按「在網頁上框選…」，框會先放在影片上，可以再微調後錄影。

### 同時錄多個分頁

到每個分頁各按一次「開始錄影」就行。彈出視窗下方的「錄影中」清單會列出全部錄影，可以個別停止，點標題可以切換到那個分頁。

### 看錄了多久

- 工具列圖示上的數字：10 分鐘內顯示 `3:25` 這種格式，之後顯示 `25m`，超過 1 小時顯示 `1h05`。在被錄的分頁顯示它自己的時間，在其他分頁顯示最早開始的那個錄影的時間。自動暫停中顯示 `暫停`。
- 滑鼠移到圖示上，會列出每個錄影的錄影時間和目前段數。
- 打開彈出視窗可以看到精確到秒的計時。
- 顯示的是實際錄到的時間，不含自動暫停的時間。

### 自動暫停

直播結束或斷線時，不用一直錄空白畫面：

- **暫停**：沒畫面也沒聲音持續 30 秒，就把目前這段存檔並暫停。「沒畫面」是指畫面幾乎全黑；用「自動框住影片」時，影片停止播放、超過 3 秒沒有新畫面（例如直播斷線卡住）或不見了也算。
- **繼續**：畫面或聲音其中一個恢復並持續 3 秒，就開一個新檔案繼續錄，檔名是恢復的時間。
- 暫停時錄影沒有真的停止，只是暫時不寫入，所以能立刻接上。
- 可以在設定裡關掉「沒畫面也沒聲音時自動暫停」，例如要錄本來就安靜又暗的畫面時。

## 檔案存在哪裡

在「下載」資料夾底下的 `ScreenRecorder` 子資料夾，資料夾名稱可以在設定裡改。每一段錄完或按停止時就會**自動下載**，不用自己按。

檔名是「分頁名_這一段開始錄的時間」：

```
YouTube - 某影片_2026-10-30_143012.webm
YouTube - 某影片_2026-10-30_150012.webm
```

如果剛好同名，瀏覽器會自動在後面加上 ` (1)`。

### 當掉之後怎麼救

錄影時，資料會先寫進瀏覽器的專用儲存空間，每一段錄完才搬到「下載」資料夾。如果瀏覽器當掉，**下次打開 Edge 時會自動把沒存到的部分存出來**，檔名一樣是當初開始錄的時間。

如果自動存檔失敗，打開彈出視窗會看到「未存的錄影」，按「存檔」可以手動再試。

### 檔案不能拖進度條？

瀏覽器錄出來的 webm 檔不會記錄總長度，有些播放器會因此不能拖進度條，被截斷的檔案也一樣。用 ffmpeg 重新封裝一次就好，只換容器、不重新編碼，速度很快：

```bash
ffmpeg -i 輸入.webm -c copy 輸出.webm
```

要轉成 mp4（影像編碼要選 H.264，預設的「自動」通常就是 H.264）：

```bash
ffmpeg -i 輸入.webm -c:v copy -c:a aac 輸出.mp4
```

### 批次轉成 MP4（方便剪輯）

`tools/` 裡有一個批次轉檔小工具，需要先安裝 [ffmpeg](https://ffmpeg.org/)。雙擊 `tools\轉成MP4.bat` 就會：

1. 找出「下載／ScreenRecorder」裡最後修改超過 1 小時的 webm，還在錄或還在下載的檔案不會動到。
2. 轉成 MP4，放到 `ScreenRecorder\轉好的MP4`。畫面不重新壓縮，畫質不變，30 分鐘的錄影大約 40 秒。
3. 轉好的原檔移到 `ScreenRecorder\已轉的原檔`。
4. 轉失敗的檔案留在原地，下次執行會重試。

資料夾不存在會自動建立；同名檔案不會被覆蓋，會在後面加 ` (2)`。同一時間只能開一個轉檔視窗，重複打開會提示你等上一個結束。

進階用法（在 PowerShell 執行）：

```powershell
# 處理別的資料夾、改成 30 分鐘以前的檔案就轉
.\tools\convert-to-mp4.ps1 -Folder "D:\錄影" -MinAgeMinutes 30

# 剪輯軟體出現聲音不同步時：重新壓縮成固定每秒 30 格（比較慢）
.\tools\convert-to-mp4.ps1 -Cfr
```

## 設定說明

| 設定 | 說明 |
|---|---|
| 每段長度 | 每隔多久存成一個檔案，選「不分段」就是停止時才存檔 |
| 存檔資料夾 | 「下載」資料夾底下的子資料夾名稱 |
| 錄聲音 | 錄分頁的聲音。錄影時你還是聽得到聲音 |
| 影像編碼 | H.264 最省 CPU（通常會用顯示卡編碼），同時錄多個分頁時建議用它 |
| 畫質 | 位元率，越高檔案越大。「自動（依影片來源）」會用量到的來源位元率的 1.5 倍（重新壓縮會損失一些，要留空間）；量不到時依解析度估算。範圍在 1～12 Mbps，每一段開始時重新決定 |
| 每秒格數 | 30 或 60 |
| 沒畫面也沒聲音時自動暫停 | 見上面「自動暫停」，預設開啟 |

## 已知限制

- 錄影中不要調整視窗大小。框選的範圍是在開始錄影時算好的，視窗大小改變後位置可能會偏掉（「自動框住影片」不受影響）。
- 框選範圍是分頁畫面上的固定位置，捲動網頁時框裡的內容也會跟著換。
- 「自動框住影片」只會改變位置，不會改善畫質：桌面解析度變低時，影片在畫面上變小，錄出來也會比較模糊。
- 自動暫停時，如果直播結束後網頁顯示的是有文字或圖片的頁面（不是黑畫面），只有用「自動框住影片」才偵測得到；換頁後也偵測不到。關掉「錄聲音」時只能靠畫面判斷。
- `edge://` 開頭的頁面、擴充功能商店等瀏覽器內建頁面不能在網頁上框選，只能錄整個分頁，或套用已存的範圍組。有些內建頁面可能完全不能錄。
- 錄影是在瀏覽器裡進行的，如果整個 Edge 都關掉，錄影也會停止。

## 檔案結構

| 檔案 | 用途 |
|---|---|
| `manifest.json` | 擴充功能設定 |
| `sw.js` | 背景程式：開始錄影、更新工具列時間、處理下載 |
| `offscreen.html` / `offscreen.js` | 隱藏的錄影程序，真正負責錄影 |
| `recorder-core.js` | 裁切、選擇編碼、寫檔的共用程式 |
| `opfs-worker.js` | 把資料即時寫進硬碟的 worker |
| `overlay.js` | 在網頁上框選範圍的畫面 |
| `video-tracker.js` | 「自動框住影片」：找影片位置並在錄影中追蹤 |
| `popup.html` / `popup.js` / `popup.css` | 工具列彈出視窗 |
| `common.js` | 設定預設值與時間格式 |
| `docs/` | README 的 logo 和 GitHub 分享預覽圖 |
| `tools/` | 批次把錄影轉成 MP4 的小工具（Windows，需要 ffmpeg） |
